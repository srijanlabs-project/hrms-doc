# Staffsy Design System

This folder contains the complete design-system documentation pack for the `Staffsy` Enterprise HRMS application.

It converts the approved visual direction into a shared implementation contract for:

- product and business teams
- UI and UX designers
- frontend engineers
- QA teams
- accessibility reviewers
- implementation and rollout teams

The design system is intentionally application-specific. It is not a generic web style guide. It is built for:

- enterprise HRMS workflows
- desktop-heavy operational workbenches
- role-aware dashboards
- dense forms and data tables
- AI-assisted decision surfaces
- responsive employee and manager self-service journeys

Design-direction summary:

- brand personality is `calm`, `trustworthy`, `enterprise-clean`, and `AI-assisted without looking experimental`
- visual hierarchy uses `deep teal`, `soft neutrals`, and `warm orange` as the primary action accent
- desktop is optimized for information density without looking heavy
- mobile keeps the same brand tone but simplifies depth, secondary controls, and density
- AI features are visible and helpful, but never visually overpower operational HR workflows

Relationship to the UI UX architecture section:

- the design system in this folder is the visual and component standard
- the `10-ui-ux-architecture` section remains the navigation, screen, and delivery-planning layer
- both must be used together during design and development
