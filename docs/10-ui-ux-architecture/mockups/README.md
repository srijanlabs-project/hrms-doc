- all operational module screens across workforce, payroll, leave, documents, assets, helpdesk, contractor operations, visitor or workplace, and health-safety workspaces
- all recruiting screens `REC-SCR-001` to `REC-SCR-006`
- all analytics screens `ANL-SCR-001` to `ANL-SCR-005`
- `89` expansion screens across organization structure, org-admin governance, identity and access, numbering or template governance, tenant-lifecycle administration, runtime operations, performance, learning, talent, compensation, ESS operations, manager workspaces, travel, expense, employee experience, asset operations, specialist operations, communications, document-action, overtime, statutory compliance, AI-copilot, integration-platform, and testing-quality workspaces
