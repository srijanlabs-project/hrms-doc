# Wave 0 to Wave 5 Mockup Assets

This folder contains `104` pixel-ready annotated SVG mockup assets covering `52` screens across the Enterprise HRMS experience library.

Coverage currently includes:

- all `30` Wave `0` provider, tenant-admin, governance, resilience, migration, and cutover screens
- `2` shared global screens: `GLB-SCR-001` and `GLB-SCR-002`
- the first `2` Wave `1` workforce-home screens: `EMP-SCR-001` and `MGR-SCR-001`
- `10` Wave `2` operations screens across workforce, payroll, leave, and documents
- `5` Wave `3` recruiting screens
- `1` Wave `4` service-workbench screen
- `2` Wave `5` analytics screens

Files:

- assets follow the standard pattern: `<screen-ref>-<slug>-desktop.svg` and `<screen-ref>-<slug>-mobile.svg`
- the full generated set currently covers:
- `W0-SCR-001` to `W0-SCR-030`
- `GLB-SCR-001` to `GLB-SCR-002`
- `EMP-SCR-001`
- `MGR-SCR-001`
- `WRK-SCR-001` to `WRK-SCR-003`

- `ANL-SCR-002` to `ANL-SCR-003`

Usage:

- use the `desktop` files for structural and visual review of full admin workspaces
- use the `mobile` files for responsive prioritization and small-screen adaptation review
- use the annotations inside each asset to understand hierarchy, interaction priority, and role boundary decisions
