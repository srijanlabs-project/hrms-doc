This folder contains `180` pixel-ready annotated SVG mockup assets covering `90` screens across the Enterprise HRMS experience library.

Coverage currently includes:

- all `30` Wave `0` provider, tenant-admin, governance, resilience, migration, and cutover screens
- all `3` shared global screens: `GLB-SCR-001` to `GLB-SCR-003`
- `27` Wave `1` workforce, manager, HR-operations, and people-profile screens across `EMP-SCR-001` to `EMP-SCR-008`, `MGR-SCR-001` to `MGR-SCR-007`, `HRO-SCR-001` to `HRO-SCR-005`, and `PEO-SCR-001` to `PEO-SCR-007`
- `18` Wave `2` operations screens across workforce, payroll, leave, documents, assets, contractor operations, and health-safety workspaces
- `6` Wave `3` recruiting screens
- `1` Wave `4` service-workbench screen
- `5` Wave `5` analytics screens
