# 1. Purpose

This folder stores the first final Screen UI design batch for the Enterprise HRMS application.

Batch `01` covers the first five role-based workspace templates defined in:

- [23-screen-ui-template-conversion-batches.md](D:/HRMS-doc/docs/10-ui-ux-architecture/23-screen-ui-template-conversion-batches.md)

The current batch includes:

1. `WS-01` My Staffsy
2. `WS-02` Manager Workspace
3. `WS-03` HR Workspace
4. `WS-04` Org Admin Workspace
5. `WS-05` Platform Admin Workspace

# 6. Notes

This batch is intended to establish the final visual language for the role-based workspace family before deeper module-level screen conversions begin.

Current position:

- desktop and mobile master boards now exist for all five templates
- this batch now establishes the reusable workspace design language for both desktop and mobile
- next step is state-variant expansion and deeper module screen conversion using these template boards as the visual baseline
