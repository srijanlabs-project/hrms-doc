# 1. Purpose

This document maps stakeholder journeys to major screen families and design responsibility areas.

# 2. Employee Journey Mapping

Primary screens:

- Employee home
- My profile
- My requests
- My documents
- My leave and attendance
- My pay and tax
- My learning and goals

Critical UX focus:

- simplicity
- mobile access
- status visibility
- clear next steps

# 3. Manager Journey Mapping

Primary screens:

- Team dashboard
- Team record overview
- Approvals inbox
- Performance review workspace
- Hiring approvals
- Team leave and attendance view

Critical UX focus:

- action prioritization
- contextual approvals
- team visibility
- low-friction decision making

# 4. Recruiter Journey Mapping

Primary screens:

- Requisition workbench
- Candidate pipeline
- Candidate profile
- Screening workspace
- Interview scheduler
- Offer workspace

Critical UX focus:

- pipeline clarity
- stage movement speed
- collaborative decision support
- candidate status traceability

# 5. HR Operations Journey Mapping

Primary screens:

- Employee master workbench
- Lifecycle action wizard
- Document verification queue
- Data correction workspace
- Timeline and audit views

Critical UX focus:

- high-density productivity
- exception handling
- effective-date confidence
- operational traceability

# 6. Payroll and Compliance Journey Mapping

Primary screens:

- Payroll dashboard
- Validation queue
- Statutory console
- Compliance calendar
- Retro and settlement workspace

Critical UX focus:

- precision
- exception surfacing
- reconciliation visibility
- audit defensibility

# 7. System Admin Journey Mapping

Primary screens:

- Forms and fields console
- Settings console
- Tenant management
- Workflow and notification admin
- Integration monitor
- Audit explorer

Critical UX focus:

- safe configuration
- dependency visibility
- change control
- rollback confidence

# 8. Organization Admin Journey Mapping

Primary screens:

- Organization admin home
- Access and roles console
- Tenant settings
- Branding and communication setup
- Workflow and policy setup
- Identity and SSO readiness views

Critical UX focus:

- setup clarity
- tenant-scoped ownership
- trust and compliance visibility
- no confusion with provider-only controls

# 9. Leadership Journey Mapping

Primary screens:

- Executive dashboard
- Workforce analytics
- Attrition analytics
- Talent review and planning views
- AI insight summaries

Critical UX focus:

- concise signal
- drill-down on demand
- trend credibility
- decision support

# 10. Usage

This mapping should be used to:

- sequence wireframes by persona
- assign design ownership
- align QA acceptance to journeys
- define release-ready design bundles by wave
